Quy tắc chuẩn hóa tự động:
  • background-color ➔ BackgroundColor3 = Color3.fromRGB(...)
  • border-radius: Xpx ➔ UICorner.CornerRadius = UDim.new(0, X)
  • border: Xpx solid C ➔ UIStroke.Thickness = X, UIStroke.Color
  • font-family ➔ Enum.Font.* tự động nhận diện
